### Tester Instructions for Download Functionality:

To verify the "Canvas Downloader" functionality:

1. **Login Required**: Log in to a Canvas LMS instance (e.g., https://canvas.instructure.com or your university's Canvas URL).
   * Note: The extension only activates on domains matching `*.instructure.com` or specific university Canvas domains.
2. **Navigate**: Go to a course page that contains files (e.g., "Modules" or "Files" section).
3. **Verify UI Injection**: The extension will automatically detect the page type and inject download buttons directly into the Canvas interface.
   * *Success Indicator*: You should see a "Download All" button injected above module headers, or an individual download icon added to Canvas's file rows.
   * *Extension Popup*: You can also click the extension icon in the Chrome toolbar to verify its active status or change download folder preferences.
4. **Test Single Download**: Click the download icon injected next to any file row.
   * **Expected Result**: The file successfully downloads via the browser's native download manager.
   * **Note on Spinners**: You may see a brief spinner. This is the **Recursive URL Unpacker** / API resolver active (see below).
5. **Test Bulk Download**: Click the "Download All" button injected into the Canvas UI.
   * **Expected Result**: All detected files will sequence through and download seamlessly.

**Logic Update Note (The "HTML Fix")**: 
We have implemented an **Authenticated API Proxy** to specifically fix the issue where intermediate policy pages (HTML wrappers) were being downloaded instead of the PDF.

1.  **API Delegation**: Instead of scraping HTML, the extension identifies the internal Canvas File ID.
2.  **Session Proxy**: It delegates the resolution to a background "Proxy" (via the Content Script). This ensures the request uses the user's active login cookies.
3.  **Direct Cluster Resolution**: It fetches the direct binary URL from the official Canvas API (`/api/v1/files/[ID]`).
4.  **Security**: If a direct API link cannot be resolved, it falls back to a **Recursive URL Unpacker** that searches the HTML for a source link, ensuring the user always gets the actual resource and never a broken `.htm` wrapper.
