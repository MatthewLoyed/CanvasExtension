Canvas Downloader v1.12.0 — reviewer instructions

This update adds offline export of available course content to the existing module/file downloader. No new permissions or login flow were added. All executable code and libraries are bundled in the package; there is no remotely hosted executable code.

Sign in using a reviewer-controlled Canvas student account with an enrolled course. No university credentials or private course content are supplied in this package. Canvas is detected by page structure, including custom school domains.

Offline export:
1. Open the Canvas dashboard. Each classic course card has an Export course button. The same action is available inside a course page.
2. Click Export course. It immediately starts an export of available pages, announcements, assignment instructions, files, and images into one ZIP. There is no selection or incomplete-discovery acknowledgement step.
3. Confirm the dialog reports current stages, current file, estimated attachment percentage, and ZIP generation progress. Close the dialog while running; the active course button shows progress and reopens the same run.
4. When saved, extract the ZIP and open index.html. Check readable saved HTML, local attachments, and links between included content. export-report.html and manifest.json explain excluded/locked/failed content and collection restrictions.
5. If content is unavailable, the export may still complete with a partial archive. Quizzes, grades, student submissions, recordings, external tools, and external-site copies are excluded. Canvas may deny a collection listing while allowing individual module-linked items. This is not a complete course backup.
6. If downloads fail, Retry missing items revalidates access and attempts failed files again. A new ZIP is saved. Cancelling stops pending work. Leaving the Canvas page interrupts an active export.

Existing file/module behavior:
- On Modules, use the dropdown to select modules/files and save separately or as a ZIP.
- On another course page, Browse course modules opens the module picker; Back to this page restores the page file list.
- Shared resources deduplicate by Canvas file identity. Distinct files with identical names are preserved. HTML and QMD attachments remain supported.

Technical notes:
Canvas API reads use the existing signed-in session, bounded queues, account verification, retries/backoff, and cancellation. Files are downloaded from the current Canvas origin or supported Canvas file-storage hosts. Permission failures and authentication failures are handled; access restrictions are not bypassed. HTML content is sanitized with bundled DOMPurify. The offline reader has a restrictive content security policy and runs without scripts. Course content and files are processed locally, not uploaded to developer servers. The extension does not request grades or student submissions.
